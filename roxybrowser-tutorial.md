# How to Use RoxyBrowser: Full Tutorial for Beginners

If you're brand new to RoxyBrowser, start here. This tutorial ties the whole series together — from installing the app to running your first isolated profile end to end.

## Step 1 — Install RoxyBrowser

Download the installer for your operating system from the <a href="https://mrait.ca/go/freebrowser" target="_blank" rel="noopener">official site</a>, run it, and sign in. The free plan gives you 5 permanent profiles to start — no trial clock.

## Step 2 — Create your first profile

Click to create a new profile and give it a descriptive name. Choose the operating system it should present as (Windows is a safe default). RoxyBrowser fills in a coherent fingerprint automatically — you don't need to touch the advanced fields to get started.

## Step 3 — Add a proxy

A proxy gives the profile its own IP. Enter the host, port, and credentials, pick HTTP or SOCKS5, and use the built-in test button before launching. Match the proxy's country to the profile's timezone.

## Step 4 — Launch and verify

Open the profile and confirm three things line up: IP location, timezone, and a fingerprint-test page with no inconsistency warnings. When they agree, the profile looks like a genuine, separate device.

## Step 5 — Manage multiple accounts

Repeat the loop — one profile per identity, one proxy per profile, one account per profile. That discipline is what keeps everything isolated. As you grow, features like window sync let you drive several profiles in parallel without cross-contaminating their sessions.

## The one-account-per-profile rule

The fastest way to link accounts you meant to keep separate is to log two of them into the same profile, or to reuse the same proxy, phone number, or recovery email across profiles. Keep each container fully self-contained.
